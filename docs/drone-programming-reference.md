# EU 无人机可视化编程：逐功能参考手册

[English](drone-programming-reference-en.md) · [设备 English](drone-device-guide-en.md) · [舰队物流 English](drone-fleet-guide-en.md)

本文对应当前 DrTech 无人机程序节点注册表与执行器。所有坐标都是当前维度的绝对 `X/Y/Z` 坐标；程序由**流程线**驱动，数值、布尔、坐标、区域和过滤器节点只在其他节点需要它们的输出时计算。

需要逐个查看全部 145 个节点的端口、属性、运行过程、失败状态和连线实例，请阅读 [全部 145 个节点逐项手册](drone-module-manual.md)。

分支、比较、布尔组合、传感器阈值与动作状态的逐项说明，另见 [条件系统详细使用手册](drone-condition-guide.md)。

## 1. 先读这一节：连线、端口与执行规则

### 1.1 端口约定

| 端口类型 | 用途 |
| --- | --- |
| `流程` | 决定执行顺序。动作节点通常有必填的 `in` 和成功后的 `next`；若有 `failed`，可为失败建立独立处理路线。 |
| `数字` | EU、数量、百分比、半径、坐标偏移、循环次数、红石强度等。接入数字端口时覆盖节点同名属性。 |
| `布尔` | 条件判断。 |
| `坐标` | 世界方块坐标。 |
| `区域` | 一组方块坐标；用于区域挖掘、放置、物流和遍历。 |
| `物品过滤` / `方块过滤` | 限定货舱物品、容器物品或方块目标。 |
| `动作状态` | 最近一次动作的标准结果，供状态判断节点使用。 |

主要端口还使用固定形状：`流程` 是箭头、`布尔` 是菱形、`数字` 是圆形、`坐标` 是准星、`区域` 是空心方框。形状与颜色同时显示。

线路也按重要性分层：彩色数据线先绘制，白色流程线后绘制并位于上层。`真`、`假`、`循环体`、`完成`、`失败`等非默认流程出口会在线路中段显示中文标签；缩放低于 75% 时标签自动隐藏。选中节点后，与选区没有直接连接的线路会自动变暗，便于沿当前流程排查；点击画布空白清除选择即可恢复全部线路亮度。这些效果只辅助阅读，不改变执行顺序。

“分组框”位于节点库的流体/扩展页。放置后在属性页设置标题、宽度、高度、颜色和折叠状态；把节点拖进框内即可自动成为成员。点击分组标题会同时选择框内全部节点，随后拖动、复制或删除会整体执行。折叠分组会隐藏成员和相关连线，再把“折叠”属性改回否即可恢复。自动布局不会移动分组及其成员。

节点右键菜单可执行复制、创建副本、删除、断开该选区全部连线、聚焦、横向/纵向对齐、自动布局、创建分组和添加注释。画布空白处右键不会清除已有选区，可把剪贴板内容准确粘贴到鼠标位置，也可在当前位置添加注释或默认分组。灰色项目表示当前条件不足，例如没有复制内容时不能粘贴、少于两个节点时不能对齐。端口右键仍只断开该端口的现有连线。

### 1.2 编辑操作

1. 从左侧节点库点击节点，节点会被放进画布。
2. **左键输出端口，再左键兼容的输入端口**以连线；**右键端口**断开该端口现有连线。
3. 左键空白处拖动可框选；按住 `Shift` 点击节点可增减多选。亮蓝框节点是主选节点，右侧属性面板只编辑主选节点。
4. 多选后可整体拖动、批量删除、复制/粘贴子图；拖动时按住 `Ctrl` 吸附到 16 格网格。“横齐”“竖齐”以主选节点为基准对齐；选择至少 3 个节点后按住 `Shift` 点击对齐按钮，可让首尾之间等间距分布。粘贴保留选择范围内部的连线，但不会复制通向外部节点的连线。
5. 有选择时“适应选区”只聚焦选中节点；点击空白清除选择后，按钮恢复为“适应全图”。中键拖动平移，滚轮缩放；画布右上角小地图显示当前视口，点击可快速跳转。
6. 选中节点后，在右侧属性面板切换属性、增减数值、选择手持物品/目标方块，或填写文本。
   对坐标、数量、半径、百分比等数字属性，可用 `<` / `>` 先选择属性，在输入框中一次输入完整数值，再点击“应用”；数值必须处于该属性显示的允许范围内。
   枚举属性会显示下拉框：点击当前值展开，直接点击目标选项；超过五项时把鼠标放在列表内滚轮浏览。方向属性显示“自动”和上下南北东西六个按钮，点击目标面即可立即保存，不需要再点“应用”。
   物品属性会显示搜索器：默认“注册表模式”，可输入 `minecraft:iron_ingot`、注册名片段或本地化名称；用 `<`/`>` 浏览，单击结果追加一条忽略 metadata 的物品规则。点击模式按钮切换“矿辞模式”，搜索 `ingotIron`、`cropWheat` 等矿辞名，单击结果追加覆盖该矿辞全部成员的规则。“手持”仍用于记录主手物品的精确 metadata 与 NBT；“移除”删除最后一条，“清空”删除全部规则。
7. 红色边框或诊断栏中的错误必须修复后，才能“写入无人机”。
8. 动作节点的可选输入优先级高于右侧属性；没有连线时才读取属性默认值。

选中长方体区域、两点区域、球体、圆柱、路径、平面、区域并集/交集/差集、偏移、扩展或收缩节点时，属性面板底部显示实时区域预览：左侧为 X/Z 俯视，右侧为 X/Y 侧视，并显示 `尺寸X×Y×Z` 和实际坐标数量。直接配置的长方体以及由静态“坐标”“数字”“坐标偏移”节点连接的形状可完整预览；变量、传感器或运行时循环产生的动态输入会明确显示“只能在运行时确定”。超过单轴 32 格或 4096 坐标时直接显示越界，不绘制误导性图形。

诊断页使用方法：右侧点击“诊断”，再用“全 / 错 / 警 / 信”筛选严重性。列表每页三条，`<` / `>` 翻页；悬浮记录可查看节点名称或别名、问题类型、缺失端口和修复建议，点击记录会把对应节点选择并移动到画布中心。若诊断属于整个程序而没有节点 UUID，则只显示说明，不执行定位。

属性诊断还会记录具体属性 ID：点击后自动切回“属性”页并选中该项。编译器会检查可达流程环；完全没有出口的环是编译错误，有条件出口但可能永远不满足的环是警告。`重复` 和 `遍历区域坐标` 是有限循环控制器，其标准回边不会被当作潜在无限循环。区域诊断同时检查单轴不超过 32 格、总体积不超过 4096 格，并优先定位需要缩小的第二角坐标属性。

将目标无人机放入编程器第二槽后会追加硬件预检诊断，这些结果只针对当前无人机，不会保存进程序卡。流体货舱相关节点要求流体货舱模块，机载合成相关节点要求合成模块；缺少时阻止写入。超过 32 个节点建议 EV、超过 96 个节点建议 IV，这只是性能与容量建议。EU 动作直接使用常量坐标且目标已加载时会预检实际电压；动态目标继续由运行时逐次检查。

批量移动、删除、粘贴和对齐会作为一条服务端 revision 命令提交：一次撤销恢复整批；若任一子命令非法，服务器回滚整批，不会留下半成品程序图。

鼠标位于画布时支持：`Ctrl+A` 全选、`Ctrl+C/V/D` 复制/粘贴/直接复制、`Ctrl+Z/Y` 撤销/重做、`Ctrl+L` 自动布局、`Ctrl+G` 网格吸附、Delete 删除、方向键微调、Home 聚焦和 Esc 清除选择。按住 `Shift` 使用方向键时步长为 16。

### 1.3 全局限制

- 单程序最多由编译器限制节点和连线数量；编辑命令由服务端 revision 校验，不能靠客户端绕过。
- 运行中的区域最多 `4096` 个方块，任一轴最大 `32` 格；超限会报错，不会只执行一部分。
- 所有会改动世界、库存或 EU 的动作都经过领地/FakePlayer、方块加载、电压和容量检查；失败可连接 `failed` 分支。
- “区域挖掘”和“区域填充”每个运行 tick 只处理一个方块，进度会保存；普通“挖掘”是对单坐标的即时破坏。

## 2. 流程与控制节点

### 开始 / 结束

| 节点 | 怎么用 |
| --- | --- |
| **开始** | 程序唯一入口。将 `next` 接到第一个动作或流程节点。 |
| **结束** | 将最后一个流程输出接入 `in`，程序正常完成。 |

### 注释

“注释”是纯编辑器节点，没有端口，也不会被无人机执行。选中节点，在属性页选择“注释内容”，可用 Enter 换行并输入最多 1024 字符、32 行；支持选择、复制、剪切和粘贴。点击应用后整次编辑只形成一条撤销记录。它支持程序卡持久化和子图复制，画布显示前两行摘要；注释不会产生不可达警告，也不计入机体等级建议。分组标题、变量名等短字符串仍使用单行输入框。

### 等待

`开始 → 等待 → 结束` 是最小可运行程序。

- `duration`（可选数字）或属性 `Ticks`：等待 tick 数，范围 `1–72000`；没有输入时默认 `20` tick。
- 节点每 tick 递减一次并保持运行状态，倒计时结束后走 `next`。

### 分支

- 必填输入：`condition`（布尔）。
- `true` / `false`：根据结果进入对应流程出口。
- 示例：`货舱占用率 → 数字比较(>= 90) → 分支`；`true` 接返航，`false` 接继续采集。

### 有限循环

- `count`（可选数字）或属性 `Count`：循环次数，范围 `0–1,000,000`。
- `body`：每轮执行的流程；应将循环体末端重新接回本节点 `in`。
- `done`：次数用尽后执行。
- `Count=0` 会直接走 `done`。不要把 `body` 直接接回而没有任何耗时/状态变化，否则可能形成无意义的高频循环。

### 条件循环

- 必填输入：`condition`（布尔）。
- 条件为真走 `body`，条件为假走 `done`；循环体末端接回本节点 `in`。
- 示例：`目标 EU 百分比 → 数字比较(< 90) → 条件循环.body → 导出 EU → 回到条件循环`。

### 遍历区域坐标

- 必填输入：`area`（区域）。
- `body`：每次给出区域内一个坐标；体末端接回本节点 `in`。
- `coordinate`：仅在 `body` 分支中有效，输出当前轮坐标。
- `done`：所有坐标处理完后执行。
- 示例：`区域 → 遍历区域坐标.coordinate → 收割作物.target`，将收割节点的 `next` 接回遍历节点。

### 等待红石 / 等待所有者

| 节点 | 输入与属性 | 行为 |
| --- | --- | --- |
| **等待红石** | `target` 可选坐标；不接时检查无人机当前位置 | 目标有红石供电时成功，否则持续等待。 |
| **等待所有者** | `radius` 可选数字或属性 `Radius`，范围 `1–128`，默认 `16` | 所有者进入无人机附近指定半径时成功，否则持续等待。 |

## 3. 移动、停机坪和安全固件

### 移动 / 返航 / 充电

| 节点 | 必填输入 | 可选输入或属性 | 作用 |
| --- | --- | --- | --- |
| **移动** | `target` 坐标 | 无 | 寻路飞往目标方块；路径不可达会失败。 |
| **返航** | `target` 坐标 | 无 | 飞往指定停机坪坐标并进入停机/充电流程。通常接“最近停机坪”或已保存坐标。 |
| **充电** | 无 | `percent` 或 `Percent`，`1–100` | 在可充电的停机坪持续充至目标百分比后继续。 |

### 停机坪引用

| 节点 | 怎么用 |
| --- | --- |
| **最近停机坪** | 值节点，输出对当前无人机可用、同所有者、同维度且电压兼容的最近停机坪坐标。可接到返航、绑定或停机坪可用判断。 |
| **绑定停机坪** | 将必填 `target` 坐标设为无人机主停机坪。建议在任务开始时绑定。 |
| **解除停机坪** | 清除当前绑定；之后低电返航只能依赖可用后备停机坪。 |
| **配置安全固件** | `return_percent` / `resume_percent` 可接数字，也可用属性 `ReturnPercent(1–95)` 与 `ResumePercent(2–100)`。默认是 `20%` 返航、`90%` 恢复。恢复值应大于返航值。 |

## 4. 世界方块与作物动作

所有这类节点都带 `in → next` 流程端口，发生拒绝、目标无效、区块未加载、缺少物品或能量时可走 `failed`。

| 节点 | 输入 | 使用方式与结果 |
| --- | --- | --- |
| **挖掘** | 必填 `target` 坐标 | 对一个方块立即执行破坏；遵从 FakePlayer/领地和掉落规则。 |
| **区域挖掘** | 必填 `area` 区域 | 依序破坏区域内的方块，每 tick 一个；适用于连续采矿或清场。 |
| **放置** | 必填 `target` 坐标；可选 `filter` 物品过滤 | 从货舱取符合过滤器的方块物品并尝试放置。空过滤器表示货舱中任意可放置方块。 |
| **区域填充** | 必填 `area`；可选 `filter` | 按区域顺序放置，每 tick 一个方块。 |
| **方块右键** | 必填 `target`；属性 `Direction`、`Sneaking` | 空手对方块执行右键互动；`Direction=AUTO` 自动选择，或选六个面之一；可模拟潜行。 |
| **使用物品** | 必填 `target`；可选 `filter`；属性 `Direction`、`Sneaking` | 用货舱中符合过滤器的物品对方块右键。 |
| **收割作物** | 必填 `target` | 收割成熟作物。兼容普通成熟作物、地狱疣、可可，以及 DrTech CropQT 杂交作物架；杂交作物保留作物 ID 与遗传属性并重置生长。 |
| **设置红石输出** | 必填 `target`；可选 `strength` 数字或属性 `Strength(0–15)` | 目标必须是无人机红石发射端点；端点六面输出该强度，`0` 关闭。 |

### 区域巡逻攻击

`patrol_attack_area` 必接区域，可接实体过滤器，并要求无人机同时安装实体扫描与战斗模块。它直接选择区域内真实实体，不需要先用“遍历区域坐标”扫描每个空方块。

- `Priority`：距离最近、最低血量、最高血量或敌对生物优先；距离和血量相同时按 UUID 稳定选择。
- `WeaponMode`：`STRONGEST` 默认使用伤害最高的武器，`PRIMARY`/`SECONDARY` 固定武器槽，`ALTERNATE` 在两槽有效武器间轮换；固定槽无有效武器时返回 `NO_RESOURCE`。
- `AttackIntervalTicks`：攻击间隔 4..40 tick，默认 8；旧程序未保存该属性时继续使用默认值。
- `HostileOnly` 默认开启，只把敌对生物列为候选；需要处理动物时必须显式关闭并建议连接实体过滤器。
- `MaxChaseTicks` 默认 1200 tick（60 秒），超时解除目标锁并走 `failed/OUT_OF_RANGE`，避免无限追击。
- `MaxChaseDistance` 默认 16 格，限制目标能够离开巡逻区域边界的最大距离；设为 0 表示目标一离开区域就停止追击，最大可设为 128 格。
- 目标选定后持续锁定、寻路和攻击，攻击冷却期间节点保持运行；轮换武器游标随无人机实体保存。
- `UntilAreaClear=true` 会依次击杀匹配目标直到区域清空；关闭时击杀一个目标即走 `next`。
- 输出 `defeated_count`，记录本次节点已经击败的目标数，可接变量、比较或显示节点。
- `NoTargetMode=COMPLETE`（默认）把空区域视为清场成功；`WAIT` 按 `RescanTicks` 周期等待新目标；`FAILED` 走 `failed/NOT_FOUND`。Boss、主人、他人所属实体和玩家攻击配置仍经过原有安全检查。
- `ReturnToAreaOnComplete=true`（默认）会在清场、单目标完成或进入 `WAIT` 重扫前返回区域内最近的可通行格。返程目标会写入节点运行状态，因此跨 tick 执行时保持稳定；当前落点阻塞或不可达时会持久记录并改选下一处，最多尝试 16 个不同落点。无可通行格或备用落点全部失败时走 `failed/UNREACHABLE`。
- `ReacquireLostTarget` 默认开启。目标 UUID 在移动途中消失、卸载或不再匹配时解除旧锁并重新扫描；关闭后直接走 `failed/NOT_FOUND`。执行器只接受扫描时选中的 UUID，不会在同一坐标自动换目标。

### 无人机钓鱼

安装 `fishing` 模块后，无人机控制界面会开放一个只接受鱼竿的独立槽。`fish_at` 必接一个已加载的水方块坐标：无人机会移动到水边，在该水格放置原版浮标并等待原版咬钩窗口，随后自动收杆。鱼线从机腹爪部连接到浮标，收杆时爪臂和鱼竿同步上提，并播放原版抛竿/收杆声音；天气、天空、水体、饵钓、海之眷顾、鱼获、经验和耐久均使用原版 `EntityFishHook` 规则。本次鱼获优先进入货舱，装不下的余量留在世界中，附近原有掉落物不会被误收。`caught` 输出本次钓获数量，可接计数或循环节点继续垂钓。

### 实体交互与装载的目标稳定性

`interact_entity` 和 `use_item_on_entity` 首次在目标坐标附近选中实体后，会锁定该实体 UUID 与目标锚点。无人机寻路、循环运行、区块保存以及回收后重新部署期间都优先使用同一实体，不会因为另一只实体靠近而临时换目标；目标死亡/消失、锚点改变或实体过滤器不再匹配时才重新选择。

`load_entity` 使用独立的装载锁，并在候选阶段先排除无主、他人所属和不支持所有权的实体，再从合法候选中按距离与 UUID 稳定选择。因此更近的非法实体不会挡住后面的本人宠物。过滤器或所有权改变、目标死亡/消失、锚点改变会使锁失效；成功装载后锁自动清除。

所有普通实体追击都有 1200 执行 tick 和相对目标锚点 128 格的统一上限，超出后解除当前锁并返回 `OUT_OF_RANGE`。执行期间客户端从无人机绘制到当前目标的渐变连线；控制界面硬件摘要显示当前实体载荷。战斗模块必须至少装入一件有效武器；空武器槽返回 `NO_RESOURCE`。主人宠物默认受保护，只有实体过滤器明确启用“允许所属实体”时才允许作为普通攻击目标。

## 5. 物品物流与过滤器

### 物品过滤 / 方块过滤

| 节点 | 输出 | 怎么配置 |
| --- | --- | --- |
| **物品过滤** | `filter` | 属性面板可在注册表/矿辞模式中搜索并单击追加，也可用“手持”读取主手物品；支持物品 ID、元数据、矿辞典、命名空间和精确 NBT 规则，最多 64 条。搜索得到的物品规则忽略 metadata，手持规则精确记录 metadata/NBT；没有规则时匹配任意物品。 |
| **方块过滤** | `filter` | 用“目标方块”读取准星方块及其 BlockState；`<`/`>` 切换 `facing`、`axis`、`half`、`age` 等状态属性，单击属性行依次选择合法值或“任意”。支持白/黑名单，最多 64 条；旧方块 ID＋metadata 规则继续兼容。没有规则时匹配任意方块。 |
| **实体过滤** | `filter` | 在数据页创建后，按 `minecraft:zombie`、注册名片段或本地化实体名搜索；单击结果追加，支持白名单/黑名单、移除末条和清空，最多 64 个实体 ID。可供实体传感、实体交互、战斗、运输和第三方扩展节点使用。 |

### 导入 / 导出物品

两个节点的结构相同：**导入**是容器/区域 → 无人机货舱；**导出**是无人机货舱 → 容器/区域。

- 目标必须二选一：接 `target` **或** `area`，不能同时接，也不能都不接。
- 可选 `filter` 限定物品；输出 `amount` 是该节点本轮/累计成功转移的数量，可用于变量、比较或日志流程。
- `Direction`：`AUTO` 或指定 `DOWN/UP/NORTH/SOUTH/WEST/EAST` 容器面。
- `MaxAmount`：本节点总转移上限；`BatchSize`：每次访问一个库存时的批量上限。
- 目标为区域时：`SearchMode=NEAREST/ORDERED/RANDOM` 决定容器选择；`SkipUnavailable=true` 时跳过不可用容器继续搜索。
- 若已成功转移部分物品，之后遇到失败会以已转移量正常结束，避免已完成部分被误判为整次失败。

### 拾取掉落物 / 丢弃物品

| 节点 | 属性与输出 | 作用 |
| --- | --- | --- |
| **拾取掉落物** | 可选 `filter`；`Radius=0.5–32`；`MaxAmount`；输出 `amount` | 从无人机附近拾取符合过滤器的实体物品到货舱。 |
| **丢弃物品** | 可选 `filter`；`MaxAmount`；输出 `amount` | 从货舱取符合条件的物品丢到无人机位置；有拾取延迟，不会立刻被同一无人机重新吸走。 |

## 6. EU 能源节点

### 导入 EU / 导出 EU / 充电至目标百分比

| 节点 | 数据方向 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- | --- |
| **导入 EU** | 目标机器 → 无人机 | 必填 `target`；可选 `amount` | `transferred` | 从具有 GT EU 输出面的机器取电。 |
| **导出 EU** | 无人机 → 目标机器 | 必填 `target`；可选 `amount` | `transferred` | 向具有 GT EU 输入面的机器充电。 |
| **充电至目标百分比** | 无人机 → 目标机器 | 必填 `target`；可选 `percent` | `transferred` | 连续向目标充电，直到达到百分比后完成。 |

共同规则：

- `amount` 未连接时使用 `MaxEU` 属性，范围 `1–1,000,000`。
- `充电至目标百分比` 未接 `percent` 时使用属性 `Percent(1–100)`；其 `transferred` 是整个持续动作的累计转移量。
- 自动查找真实的输入/输出面，严格检查电压和安培包；单 tick 不超过无人机机体允许的一安培包。低压目标不会被高压无人机强灌。
- 目标只接收部分 EU 时，未接收部分会回写无人机；没有有效 EU 能力时失败，不会生成 EU。

### EU 传感

| 节点 | 必填输入 | 输出 |
| --- | --- | --- |
| **EU 电量** | 无 | 无人机自身当前 EU 百分比。 |
| **目标 EU** | `target` | 目标机器当前存储 EU；没有有效 EU 能力时返回 `-1`。 |
| **目标 EU 容量** | `target` | 目标机器最大 EU 容量；无能力时为 `-1`。 |
| **目标 EU 百分比** | `target` | 目标机器 EU 百分比；无能力时为 `-1`。 |

## 7. 基础值、变量、数学和条件

### 基础值

| 节点 | 输出 | 属性/用途 |
| --- | --- | --- |
| **数字** | 数字 | `Value` 是任意有限数；用于数量、比较、偏移和百分比。 |
| **布尔** | 布尔 | `Value=true/false`。 |
| **坐标** | 坐标 | `X/Y/Z`，用于动作目标。 |
| **区域** | 区域 | `X1/Y1/Z1` 与 `X2/Y2/Z2` 两角形成长方体。 |
| **停机坪引用** | 停机坪引用（可接坐标） | 在数据页创建；右侧按名称、UUID 或坐标搜索当前玩家、当前维度的停机坪。点击结果保存 UUID 与坐标快照，可接移动、绑定、返航、充电前判断和各类坐标目标。列表会标记在线/离线与可用 EU。 |
| **程序引用** | 程序引用 | 在机器页创建；只列出当前玩家成功写入并通过验证的服务端程序快照。支持名称、UUID、revision 搜索，选择后锁定 `ProgramId + revision`。旧 revision 会提示失效；调用/返回执行节点将在子程序阶段提供。 |
| **坐标偏移** | 坐标 | 必填 `base`；可选 `x/y/z` 覆盖属性 `X/Y/Z`，生成偏移后的坐标。 |
| **动态区域** | 区域 | 必填 `first`、`second` 两个坐标，运行时生成长方体。 |

### 变量

变量在无人机本次运行中保存，并随运行状态持久化。名称为 `Name` 属性（最长 32 字符）；空名称自动使用 `value`。

| 节点 | 怎么用 |
| --- | --- |
| **读取变量** | 输出指定变量当前数字；未写入时为 `0`。 |
| **赋值变量** | 必填 `value`，把数字写入指定变量后走 `next`。 |
| **累加变量** | 必填 `amount`，在指定变量上加该数后走 `next`。 |

### 数学和布尔

| 节点 | 输入 | 属性 | 输出/注意事项 |
| --- | --- | --- | --- |
| **数字运算** | 必填 `left/right` 数字 | `Operator`: `+ - * / % min max` | 输出结果；除以零、模零、无穷或 NaN 会使程序报错。 |
| **数字比较** | 必填 `left/right` 数字 | `Operator`: `== != < <= > >=` | 输出布尔，可接分支或循环条件。 |
| **布尔逻辑** | 必填 `left/right` 布尔 | `Operator`: `AND OR XOR` | 输出布尔。 |
| **逻辑非** | 必填 `value` 布尔 | 无 | 输出反转后的布尔。 |
| **上次状态** | 无 | 无 | 输出上一动作的标准状态。 |
| **上次错误** | 无 | 无 | 输出上一动作的错误文本。 |
| **状态判断** | 必填 `status` 动作状态 | `Status`: `SUCCESS/NOT_FOUND/NO_SPACE/NO_RESOURCE/NO_ENERGY/OUT_OF_RANGE/UNLOADED/DENIED/UNREACHABLE/INVALID_TARGET/FAILURE/ERROR` | 输出是否与所选状态相同。 |

## 8. 货舱、世界和停机坪传感

| 节点 | 输入 | 输出与含义 |
| --- | --- | --- |
| **货舱物品数** | 可选物品过滤 | 货舱内符合过滤器的物品总数。 |
| **货舱空槽** | 无 | 当前可用空槽数量。 |
| **货舱占用率** | 无 | 货舱占用百分比。 |
| **库存物品数** | 必填 `target`，可选物品过滤 | 读取目标库存的物品数量；属性 `Direction` 可指定面。 |
| **红石强度** | 必填 `target` | 读取目标方块接收到的红石强度。 |
| **输出红石强度** | 必填 `target` | 读取目标方块当前对外输出的红石强度。 |
| **光照等级** | 必填 `target` | 属性 `LightType=MAX/BLOCK/SKY`，输出总/方块/天空光照。 |
| **方块匹配** | 必填 `target`，可选方块过滤 | 输出目标是否匹配过滤规则。 |
| **坐标可达** | 必填 `target` | 输出导航系统是否可达目标坐标。 |
| **停机坪可用** | 必填 `target` | 输出该坐标的停机坪是否在线、所有者/电压兼容、启用且可用。 |
| **区域方块计数** | 必填 `area`，可选方块过滤 | 输出区域内符合过滤器的方块数；`Limit=1–4096` 作为提前停止上限。 |

## 9. 区域形状和区域运算

所有节点都输出 `区域`，可接区域挖掘、区域填充、区域物流、遍历区域坐标或区域传感器。

| 节点 | 输入与属性 | 结果 |
| --- | --- | --- |
| **球体区域** | 必填 `center`；可选 `radius` 覆盖 `Radius(1–9)`；`Hollow` | 以中心为圆心的实心或空心球体。 |
| **圆柱区域** | 必填 `center`；可选 `radius/height` 覆盖 `Radius(1–8)`、`Height(1–16)`；`Hollow` | 中心是底层圆心、向上延伸的实心或空心圆柱。 |
| **路径区域** | 必填 `first/second`；可选 `radius` 覆盖 `Radius(0–3)` | 两点之间的体素路径，可加粗。 |
| **区域并集** | 必填 `first/second` 区域 | 两个区域的所有不重复坐标。 |
| **区域交集** | 必填 `first/second` 区域 | 两区域共有坐标。 |
| **区域差集** | 必填 `first/second` 区域 | 第一个区域中去掉第二个区域的坐标。 |
| **区域偏移** | 必填 `area`；可选 `x/y/z` 覆盖 `X/Y/Z(-32–32)` | 将整个区域平移。 |
| **区域包含坐标** | 必填 `area/coordinate` | 输出给定坐标是否属于该区域。 |
| **区域坐标数** | 必填 `area` | 输出区域实际坐标总数。 |
| **空间平面区域** | 必填 `origin/first/second` | 由原点和两条边向量生成的体素平面。 |

> 形状或组合后的区域同样受运行时 `4096` 方块与单轴 `32` 格限制；建议先用“区域坐标数”配合“数字比较”保护大范围任务。

## 10. 可直接照抄的连线示例

### 10.1 定点收割并自动返航

`开始 → 读取/固定坐标 → 收割作物 → 货舱占用率 → 数字比较(>=90) → 分支`

- `true → 最近停机坪 → 返航 → 结束`
- `false → 等待(20) → 回到收割作物`

### 10.2 区域物流

`开始 → 区域 → 物品过滤 → 导入物品(area + filter) → 导出物品(target + filter) → 结束`

在导入/导出节点设置 `MaxAmount` 与 `BatchSize`；需要多箱体时只给其中一个节点接区域，不要同时接坐标和区域。

### 10.3 目标机器充电到 90%

`开始 → 目标坐标 → 数字(90) → 充电至目标百分比 → 结束`

将目标坐标接到 `target`、数字接到 `percent`；需要根据已转移 EU 记账时，把 `transferred` 接到“赋值变量”。

### 10.4 红石控制

`开始 → 红石发射端点坐标 → 数字(15) → 设置红石输出 → 等待(20) → 数字(0) → 设置红石输出 → 结束`

两个“设置红石输出”节点都接同一端点坐标，分别输出 15 和 0。
