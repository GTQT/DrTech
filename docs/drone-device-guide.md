# EU 无人机设备使用说明

[English](drone-device-guide-en.md) · [舰队物流说明](drone-fleet-guide-en.md) · [OpenComputers English](opencomputers-drone-example-en.md)

本说明对应 DrTech 原生 EU 无人机系统。设备名称均使用 `drtech.machine.*` 本地化键；不要使用旧的 `Drone Pad` 作为本系统的操作入口。

## 1. 无人机编程器（EV）

用途：编辑程序卡，并把已经通过编译的程序写入无人机。

1. 给编程器接入 EV 或更高等级 EU 电力。
2. 打开界面；底部是玩家物品栏。
3. 将**无人机程序卡**放入左上槽。首次使用会生成包含开始和结束节点的基础程序。
4. 从左侧节点库添加节点；左键依次点击输出端口和输入端口以建立连线，右键端口可断开连线。
5. 在右侧属性面板设置节点参数；红框节点或下方诊断中的错误必须先处理。
6. 将目标**可编程 EU 无人机**放入右上槽，点击“写入无人机”。一次写入消耗 `8192 EU`。

编辑器常用操作：

- 搜索框支持中文节点名，例如“收割”“停机坪”“红石”。
- 左键空白处拖动可框选；按住 `Shift` 点击节点可逐个加入或移出选择。浅蓝框表示已选节点，亮蓝框表示右侧属性面板当前编辑的主选节点。
- 多选后拖动任意一个选中节点会整体移动；拖动时按住 `Ctrl` 可将节点吸附到 16 格编辑器网格。“删除”会批量删除。
- “横齐”“竖齐”分别以主选节点为基准排成同一行或同一列；至少选择 3 个节点后，按住 `Shift` 点击对应按钮可在横向或纵向等间距分布，首尾节点保持不动。
- “复制/粘贴”支持整个选中子图：所有节点都会取得新 UUID，选中节点之间的内部连线会保留，连接到选择范围外的线不会复制。
- 批量移动、删除、粘贴和对齐均为一次服务端事务；一次“撤销”即可恢复整批操作，任一子操作无效时整批不会写入。
- 可设置节点别名、断点、程序名；撤销/重做会保留这些修改。
- 中键拖动画布可平移，滚轮可缩放；有选择时右下按钮显示“适应选区”，没有选择时显示“适应全图”。
- 画布右上角小地图显示全图节点、蓝色选区、绿色运行节点和白色当前视口框；左键点击小地图位置可立即将画布中心移动到那里。
- “复位”恢复 100% 缩放和默认视角；按住 `Shift` 点击“复位”执行自动布局。选择两个以上节点时只布局选区，否则布局全图。自动布局按流程线从左向右分层，只改坐标，不改程序连线。
- 右侧可在“属性 / 无线 / 诊断”三页之间切换。“诊断”页支持“全 / 错 / 警 / 信”筛选和翻页；每条记录悬浮可查看节点别名、端口及中文修复建议，点击记录会选择并居中对应节点。
- 如果仍有编译错误就点击“写入无人机”，界面会自动切到“诊断”的错误筛选页；先逐项修复，再重新写入。没有具体节点的全局错误会显示，但无法定位。
- 属性错误会在点击诊断后自动切回“属性”页并选中出错属性。区域超过任一轴 32 格或总体积 4096 格时，会定位到建议缩小的 X2/Y2/Z2。
- “流程循环没有出口”属于错误，必须接出通往循环外或“结束”的流程线；“流程循环可能永远运行”属于警告，应确认 While 条件最终能变为假。有限“重复”和“遍历区域坐标”的正常回边不会产生该警告。
- 选中“坐标”或“区域”常量节点后可点击“进入世界选择”。界面会自动关闭：坐标节点右键一个方块即可写入，区域节点依次右键两个角；选择第一角后会显示随准星变化的青色区域外框，潜行右键可取消。结果由服务端直接保存到编程器中的程序卡，重新打开界面即可继续编辑。
- 鼠标放在诊断记录区域滚动滚轮，可前后浏览诊断页。目标无人机放入第二槽后，诊断页还会检查流体货舱模块、合成模块和机体规模建议；缺少必需模块时不会消耗 EU，也不会写入程序。
- EU 导入、导出或充电节点若直接连接“坐标”常量，且目标区块当前已加载，编程器会提前检查目标设备电压。由偏移、遍历或传感器产生的动态坐标无法静态确定，仍由无人机运行时安全拒绝不兼容电压。
- 左侧“流程”页的“注释”节点用于在画布记录说明。选中后在属性页选择“注释内容”，输入最多 128 字并应用；注释直接显示两行摘要，可跟随程序卡复制、撤销和重做，但无人机不会执行它。
- 端口同时使用颜色和形状：流程为箭头、布尔为菱形、数字为圆形、坐标为准星、区域为空心方框；即使无法区分颜色也能判断主要数据类型。

画布快捷键（鼠标需位于画布，且不能正在编辑文本框）：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+A` | 全选全部节点 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴选中子图 |
| `Ctrl+D` | 直接复制一份选中子图 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+L` | 自动布局选区或全图 |
| `Ctrl+G` | 将选中节点立即吸附到 16 格网格 |
| `Delete` / `Backspace` | 批量删除选中节点 |
| 方向键 | 每次移动选区 1 格；按住 `Shift` 时每次移动 16 格 |
| `Home` | 适应选区；未选择时适应全图 |
| `Esc` | 取消连线并清除选择 |

## 2. 无人机舰队控制器（EV）

用途：集中查看本人名下的已注册无人机和持久化舰队任务，并远程控制在线无人机。

1. 使用 EV 机器外壳、EV 传感器、EV 发射器、EV 电路和铝单线缆合成控制器，并接入 EV 或更高等级 EU。
2. 打开界面后，上半区分页显示无人机机体、本地化运行状态、在线状态、维度、坐标、电量、货舱和 ID；下半区按最新优先分页显示最多 128 项任务。
3. 选择在线无人机后可执行“启动”“停止”或“召回”。离线、跨所有者、心跳过期或实体未加载的目标会被服务端拒绝。
4. 控制器只同步当前玩家拥有的无人机和任务；任务提交、预约、完成、失败和取消也会再次校验所有者 UUID。
5. 任务队列、重试状态和有效库存预约保存在世界数据中。服务器重启时，运行中的任务会进入退避重试并释放旧预约。
6. 每项物流任务显示资源类型、状态/阶段、资源 ID、已交付/已取/请求量、预约量、源/目标端点、承载无人机、重试次数和本地化失败原因；非终态任务可直接点击“取消任务”。取消操作再次验证玩家距离和任务所有者。
7. 控制器使用 EV 机壳、正面/顶部发射器面、紫色信标和紫色网络节点专属贴图形成独立外观。当前玩家最多 128 个在线或返航中的物流任务会同步为金色源目标世界连线；每条线只在其所在维度显示。关闭界面后保留最后一次快照，退出或切换世界时自动清空。

## 3. HV / EV / IV 无人机停机坪

用途：作为无人机的固定母港，自动同步程序、充电、发射和回收。

1. 选择与无人机相同或更高电压等级的停机坪，并接入对应 EU 电力。
2. 左槽放入无人机，右槽放入已编辑的程序卡。
3. 停机坪会自动把程序卡的程序同步给槽内无人机，并持续充电。
4. 无人机达到至少 `90%` 电量后，点击“发射”；也可以开启“自动发射”。电量不足、槽位为空、设备未启用、所有者不匹配或生成失败时，发射按钮会在动作栏显示具体原因。
5. 停机坪发射会保留无人机的程序、运行变量、物品栏和电量，但会清除上一次回收物品中残留的“返航/充电”安全状态，并提供 40 tick 离坪保护，避免刚生成就被再次回收。
6. 需要结束任务时点击“召回”。手动召回会立即暂停程序并保留当前节点、变量和节点进度；回收和再次发射后仍保持暂停，必须在无人机面板或无线调试区点击“继续”。无人机的低电安全固件自动返航仍会在充电后恢复任务。
7. “启用”关闭时不能发射；停机坪会记录所有者，其他所有者的无人机不能占用该停机坪。
8. 停机坪顶部追加蓝色同心导航专属贴图；四角引导灯会按启用与红石条件显示绿色或红色，中心信标和槽内充电进度在 64 格内可见；回收锁定、充电、起飞和降落都有对应声音或粒子反馈。

等级对应：

| 停机坪 | 适用无人机 |
| --- | --- |
| HV 无人机停机坪 | HV 可编程 EU 无人机 |
| EV 无人机停机坪 | EV 可编程 EU 无人机 |
| IV 无人机停机坪 | IV 可编程 EU 无人机 |

## 4. 原生物流端点（EV）

三种端点均在首次打开时绑定所有者，并以稳定 UUID、类型、维度和坐标登记到世界端点目录。其他玩家无法通过目录枚举这些端点。

- **物品端点**：提供 9 格 Forge 物品缓冲，可被无人机导入/导出物品节点和外部物流管道访问。
- **流体端点**：提供 `64000 mB` Forge 流体缓冲，可被无人机导入/导出流体节点和流体管道访问。
- **EU 端点**：提供 EV 级 GT EU 缓冲，可作为无人机 EU 导入/导出及充电节点的目标。

三类端点在机器壳顶部拥有按资源类型区分的立体结构和正面专属贴图：物品端点为橙色箱体/仓储图标，流体端点为蓝色储罐/液滴图标，EU 端点为黄色能量柱/闪电图标。编程器正面追加青色终端贴图，舰队控制器使用独立的紫色控制台、显示面板、天线和网络节点贴图；立体结构参与正常世界深度遮挡，不是穿墙全息标记。

三种设备都使用 EV 机器壳和铝单线缆合成；分别额外需要机械臂与箱子、电泵与桶、或 EV 电路与能源晶体。

界面可配置目标请求库存、单次提供上限、优先级、最低保留和最大总库存。请求量为 `0` 时该端点不自动创建补货需求；提供上限或最大库存为 `0` 时表示不额外设策略上限，但实际接收量始终受端点物理容量限制。数值按钮普通点击、按住 Shift、按住 Ctrl 分别使用小/中/大步长：物品为 `1/16/64`，流体为 `100/1000/16000 mB`，EU 为 `1/4/64` 个 EV 能量包；优先级始终每次调整 1。

白名单输入资源 ID（例如 `minecraft:iron_ingot`、流体名称或 `gregtech:eu`），点击“添加”保存，使用 `<`/`>` 浏览，点击“删除”移除当前项，“清空”恢复为不限制；最多 64 条。流体端点已有流体时只接受同种流体。三类端点会在库存、配置或所有者变化后立即发布真实快照，并用周期心跳更新在线状态和外部 EU 变化。

当目标请求库存低于设定值时，舰队控制器自动从同所有者、同维度、同类型在线来源中选择资源，应用白名单、优先级、提供上限、最低保留、最大库存、物理容量和已有预约，原子锁定源/目标数量后分配无人机。物品使用真实货舱，流体要求流体货舱模块，EU 要求 EU 接口模块并使用独立于飞行电池的运输 EU。取货、飞行、交付均分 tick 进行。

端点离线、目标满、寻路失败或服务器重启会释放旧预约并按指数退避重试。已经取出的资源始终绑定原承载无人机，其他无人机不能接管账面载荷；最终失败或取消后，承载无人机携货返回绑定或备用停机坪。成功保存到停机坪后任务显示“已恢复”，资源仍保留在无人机物品中供人工处理。

## 5. 无人机红石发射端点

用途：让程序化无人机向世界输出红石信号。

1. 将端点放在要控制的红石装置旁；它不需要接 EU 电缆。
2. 在程序中添加“设置红石输出”节点，并为节点提供端点坐标和 `0–15` 的信号强度。
3. 执行后端点六个面都会输出相同强度的原版红石信号；再次写入 `0` 即关闭。
4. EU 消耗由执行动作的无人机承担，端点本身只保存并输出信号。

## 6. 可编程 EU 无人机

用途：携带已写入的程序，在世界中执行移动、挖掘、收割、物流、EU 转移和红石等节点任务。

- 右键无人机物品打开控制面板；潜行右键可进行回收操作。
- 建议先在编程器写入程序，再放入同级停机坪充电并发射。
- 低于安全固件返回阈值时会中断任务返航；默认返航阈值为 `20%`，恢复阈值为 `90%`，可用“配置安全固件”节点调整。
- 收割节点兼容 DrTech CropQT 杂交作物架：通过原生收获流程保留作物 ID 与遗传属性并重置生长阶段。
- 已安装模块会显示对应机体外挂；战斗武器和钓鱼鱼竿使用槽内真实物品模型悬挂在爪子下方。货舱灯按占用率从绿色变为红色，耐久损失超过一半时出现烟雾，起飞和降落时显示环形世界标记。
- 当前执行坐标、导航路径和放置目标可通过世界预览显示；放置目标使用青色全息线框。已加载的停机坪显示蓝色信标，舰队控制器显示紫色信标；这些设备信标只表示客户端已加载设备，实际查看和控制权限仍由服务端校验。
- 旋翼、起降、充电、工具臂、破坏、放置、程序状态、低电、受伤和死亡声音均按来源限频并随距离衰减；超出事件有效距离时不会播放。
- 暂停后执行“继续”，或从舰队控制器再次执行“启动”、重启程序时会强制重新同步旋翼活动状态并恢复转动；无人机不会再触发生物脚步声，飞行使用独立的 `drone.rotor` 机械旋翼音源。
- 执行钓鱼节点时无人机固定移动到目标水面上方两格再抛竿；鱼竿优先取自专用鱼竿槽，也可从机载物品栏或目标水平 3 格内的已加载容器自动转入专用槽。悬停位置被阻挡时安全返回路径不可达，不会钻入水面。

程序中每一个节点、端口、属性和限制的说明见 [无人机可视化编程逐功能参考](drone-programming-reference.md)。

神秘时代 6 联动使用“搬运神秘源质”节点：安装炼金升级并在专用槽放入普通或虚空源质罐后，连接源质冶炼炉坐标即可运行；罐子区域可选，连接时直接扫描区域内的源质罐且不要求管道，未连接时自动扫描炉体周围 5×5×5。目标优先选择标签匹配且未满的源质罐。无人机以专用槽内的罐子作为搬运介质，搬运时爪下显示真实罐子、当前要素颜色和提拉摆动动画；两次成功搬运之间服务端强制至少间隔 10 tick。

条件判断、状态码和常用条件连线见 [无人机条件系统详细使用手册](drone-condition-guide.md)。

移动、挖掘、放置、伐木、补种、作物、物品/流体物流、EU、传感器、区域等全部节点的逐项操作见 [全部 145 个编程模块手册](drone-module-manual.md)。

## 7. 可直接套用的无人机案例

以下案例中的“坐标”和“区域”都使用当前维度的绝对坐标。先在编程器中完成连线、确认诊断页为 0 个错误，再写入无人机并从停机坪发射。

### 案例 A：CropQT 杂交农场单轮收获

**用途**：巡检一个 CropQT 作物架区域，只收成熟作物；保留作物 ID、杂交遗传数据和作物架，掉落物自动装入货舱。

准备：将 CropQT 作物架所在的单层范围设为“区域”；确保无人机有足够货舱空间。建议把“拾取掉落物”的 `Radius` 设为 `2–4`。

```text
开始 → 遍历区域坐标.in
区域.value → 遍历区域坐标.area

遍历区域坐标.body → 收割作物.in
遍历区域坐标.coordinate → 收割作物.target
收割作物.next → 拾取掉落物.in
收割作物.failed → 遍历区域坐标.in
拾取掉落物.next → 遍历区域坐标.in
拾取掉落物.failed → 遍历区域坐标.in

遍历区域坐标.done → 返航.in → 结束.in
停机坪坐标.value → 返航.target
```

`收割作物.failed` 通常表示该格尚未成熟；直接回到遍历节点即可跳过。货舱满会使拾取失败，此时不要接回遍历，而应改接“返航 → 导出到仓库 → 结束”。

### 案例 B：只开采指定矿石并收集掉落物

**用途**：在有限区域内只破坏符合方块过滤器的矿石，空气、石头和非目标方块保持不动。

准备：创建“方块过滤”，在右侧属性中加入目标矿石方块或 BlockState；区域上限为单轴 32 格、总体积 4096 格。挖掘是瞬间破坏，但仍受领地、硬度、工具和 Forge 事件限制。

```text
开始 → 遍历区域坐标.in
区域.value → 遍历区域坐标.area

遍历区域坐标.coordinate → 方块匹配.target
方块过滤.value → 方块匹配.filter
方块匹配.result → 分支.condition
遍历区域坐标.body → 分支.in

分支.true → 挖掘.in
遍历区域坐标.coordinate → 挖掘.target
挖掘.next → 拾取掉落物.in → 遍历区域坐标.in
分支.false → 遍历区域坐标.in
遍历区域坐标.done → 返航.in → 结束.in
```

若“挖掘”发生权限拒绝或目标区块卸载，属于终止性错误；先在无人机面板或无线调试查看错误，再调整区域或领地权限。掉落物不会被“挖掘”自动装入，必须保留“拾取掉落物”节点。

### 案例 C：两个箱子之间的定量物流

**用途**：从来源箱取指定物品，带到目标箱；适合燃料补给、成品转运或原料配送。

准备：创建“物品过滤”，指定一种物品、矿辞或允许的多个规则；分别创建来源箱和目标箱坐标。导入和导出的 `MaxAmount` 设为本次总量，例如 `512`；单次实际搬运仍受无人机等级与效率模块限制。

```text
开始 → 导入.in → 导出.in → 返航.in → 结束.in
来源箱坐标.value → 导入.target
物品过滤.value → 导入.filter
目标箱坐标.value → 导出.target
物品过滤.value → 导出.filter
停机坪坐标.value → 返航.target
```

建议处理失败线：`导入.failed → 结束`（来源暂时无货）；`导出.failed → 返航`（目标已满或货舱无物）。目标必须是暴露物品能力的库存；若只知道一片仓库，可为导入/导出改接 `area` 并启用区域搜索。

### 案例 D：GT 多方块自动维护后恢复生产

**用途**：检查 GT 多方块控制器；需要维护时自动使用无人机货舱内的 GT 工具维修，并重新启用机器。

准备：无人机货舱放入实际声明为 `wrench`、`screwdriver`、`mallet`、`hammer`、`wirecutter`、`crowbar` 的工具。目标坐标必须是**多方块控制器**，不是维护仓。默认 `RequireAll=true`，即六类故障所需工具必须齐全才会动手。

```text
开始 → 分支.in
控制器坐标.value → 机器需要维修.target
机器需要维修.result → 分支.condition

分支.true → 维修 GT 机器.in → 设置机器启用（维修后）.in → 结束.in
控制器坐标.value → 维修 GT 机器.target
控制器坐标.value → 设置机器启用（维修后）.target

分支.false → 设置机器启用（无需维修）.in → 结束.in
控制器坐标.value → 设置机器启用（无需维修）.target
```

`维修 GT 机器.failed` 可接“返航”或“结束”。分支的两条路线各放一个“设置机器启用”节点，避免将两条流程边接入同一个输入端口。若状态是 `NO_RESOURCE`，补齐工具；若是 `INVALID_TARGET`，检查是否点到了控制器方块及结构是否成型。

### 案例 E：把重复流程做成可调试的子程序

**用途**：把“农场单轮收获”“矿区单轮巡检”等重复逻辑做成独立程序，主程序只负责调度。

1. 先创建并完成子程序，例如命名为“农场单轮”；它必须从“开始”走到“结束”。
2. 将该程序写入任意兼容无人机一次，使其通过验证并登记到当前玩家的安全程序库。
3. 新建主程序，在“机器”页加入“程序引用”和“调用子程序”。选中“程序引用”，在右侧 `Program` 选择刚才的“农场单轮”。
4. 按下列连线并将主程序写入实际执行无人机：

```text
开始.next → 调用子程序.in → 结束.in
程序引用.value → 调用子程序.program
```

调用节点会以固定的 `ProgramId + revision` 执行子程序；子程序的“结束”会自动返回调用节点的下一步。编辑并重新写入子程序后，旧引用会提示 revision 失效，需在主程序的“程序引用”重新选择。暂停在调用节点时，“步入”进入子程序，“步过”运行完整子程序并停在主程序的下一节点；子程序内部断点仍有效。当前子程序不提供输入/输出参数，复杂数据请先拆成独立流程。
